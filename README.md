# 🌱 Renewable Energy Monitoring & Carbon Footprint Tracker

A full-stack MERN web application designed to help organizations monitor electricity consumption, renewable energy generation, and carbon emissions through an easy-to-use dashboard.

## 📌 Project Overview

The Renewable Energy Monitoring & Carbon Footprint Tracker helps organizations track their energy usage and understand their environmental impact.

The application will provide sustainability metrics and visualizations to support better energy-management decisions.

## 🚀 Features

- ⚡ Electricity consumption monitoring
- ☀️ Renewable energy generation tracking
- 🌍 Carbon footprint calculation
- 📊 Sustainability metrics and dashboards
- 📈 Interactive charts using Chart.js
- 🔐 User authentication using JWT
- 📧 Email notifications using Nodemailer
- ☁️ Cloudinary integration for media management
- 🗄️ MongoDB database
- 📱 Responsive web interface

## 🛠️ Technology Stack

### Frontend
- React.js
- Chart.js

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication & Services
- JWT
- Nodemailer
- Cloudinary
